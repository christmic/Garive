# mobile/iosApp/

> **iOS app.** SwiftUI UI, native Apple frameworks. Thin tier —
> calls into `mobile/shared/` via SKIE for the Kotlin bridge.

## Stack

- **UI**: SwiftUI (iOS 17+)
- **State**: `@Observable` macro
- **Async**: Swift Concurrency (`async`/`await`, `AsyncSequence`)
- **Min target**: iOS 17
- **Build**: Xcode (workspace generated by the KMP project)

## Module Layout

```
iosApp/
├── Sources/
│   ├── UI/        SwiftUI views, ViewModels, themes, navigation
│   ├── Bridge/    Swift ↔ Kotlin bridge (SKIE-generated entry points)
│   └── App/       App entry, lifecycle glue
├── iosApp.xcodeproj   or   iosApp.xcworkspace (generated)
└── README.md
```

## Conventions

- Views are `struct`s conforming to `View`. No `UIViewController`
  unless SwiftUI genuinely can't express something (rare).
- ViewModels are `@Observable` classes; UI observes via `@State`
  / `@Bindable`.
- Navigation via `NavigationStack` (iOS 16+).
- Push notifications: APNs (`UserNotifications.framework`).
- Keychain: native `Security.framework` for token storage.

## Bridge (`Sources/Bridge/`)

- Generated by [SKIE](https://skie.touchlab.co/) from
  `mobile/shared/`.
- Exposes Kotlin `Flow<T>` as `AsyncSequence<T>`; `suspend fun`
  as `async` Swift functions; sealed classes as Swift enums with
  associated values.
- **Never hand-roll a coroutine / Flow bridge.** If SKIE can't
  express something, file an issue — don't write custom glue.

## Depends On

- `mobile/shared/` (via the KMP framework).

## Build

Open `iosApp.xcworkspace` in Xcode and ⌘R. The KMP framework
is built by Gradle as part of the Xcode build phases
(configured in the workspace).
